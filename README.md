# 🏭 Thales 6G Smart Factory Diagnostic Intelligence Dashboard

An enterprise-grade, real-time industrial telemetry dashboard built with Python, Streamlit, and Plotly.

## 🌟 Key Features
- **6G URLLC Telemetry Monitoring:** Sub-millisecond latency tracking and packet loss analysis.
- **Physical Wear & Stress Analytics:** Correlates operating temperatures, mechanical vibrations, and energy consumption.
- **Automated FMEA Engine:** Root-cause analysis for machine degradation and failure modes.
- **Continuous 10-Section Diagnostic Flow:** Structured end-to-end telemetry inspection stream.

## 🛠️ Tech Stack
- **Framework:** Streamlit
- **Data Engine:** Pandas, NumPy
- **Visualization:** Plotly
